Using the embedding formalism, we denote fields lying in the embedding space as Φ\PhiΦ and fields lying in the original space as ϕ\phiϕ. We require two properties for Φ\PhiΦ:

We can now find the form of correlation functions, or nnn-point functions (nnnPF), for CFT’s. Here we derive them for scalars.

1 point functions

Scalars

⟨Φ(P)⟩\langle \Phi (P)\rangle⟨Φ(P)⟩

This needs to be a scalar. The only scalar of coordinates that we can construct using a single coordinate is the absolute value

⟨Φ(P)⟩=const?\langle \Phi (P)\rangle = const?⟨Φ(P)⟩=const?

Since the field has to scale according the second property defined above, we only have two possibilities:

⟨Φ(P)⟩={0if Δϕ≠01if Δϕ=0\langle \Phi (P)\rangle = \left\{\begin{array}{ll} 0 &\textrm{if }\Delta_{\phi}\neq 0\\ 1 &\textrm{if }\Delta_{\phi}= 0 \end{array}\right.⟨Φ(P)⟩={01​if Δϕ​=0if Δϕ​=0​

The only operator allowed to have dimension 0 is the identity.

2 point functions

Scalars

⟨Φ1(P1)Φ2(P2)⟩=f(P1⋅P2)\langle \Phi _1(P_1)\Phi _2(P_2)\rangle = f(P_1\cdot P_2)⟨Φ1​(P1​)Φ2​(P2​)⟩=f(P1​⋅P2​)

From now on, assume that 2PF are “diagonal” in the space of operators (only non 0 2PF are those of an operator with itself).
