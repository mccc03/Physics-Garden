Steane code

Jan 18, 20267 min read

The Steane code is obtained by applying the CSS code procedure to the [7,4,3][7,4,3][7,4,3]-Hamming code.
The classical parity checks are:

x0+x1+x3+x4=0x_0+x_1+x_3+x_4=0x0​+x1​+x3​+x4​=0 x0+x2+x3+x5=0x_0+x_2+x_3+x_5=0x0​+x2​+x3​+x5​=0 x1+x2+x3+x6=0x_1+x_2+x_3+x_6=0x1​+x2​+x3​+x6​=0

Following the CSS procedure, we obtain a stabilizer group associated to the two sets:

SX={X0X1X3X4,X0X2X3X5,X1X2X3X6},\mathcal{S}_X = \left\{X_0X_1X_3X_4,X_0X_2X_3X_5,X_1X_2X_3X_6\right\},SX​={X0​X1​X3​X4​,X0​X2​X3​X5​,X1​X2​X3​X6​}, SZ={Z0Z1Z3Z4,Z0Z2Z3Z5,Z1Z2Z3Z6},\mathcal{S}_Z = \left\{Z_0Z_1Z_3Z_4,Z_0Z_2Z_3Z_5,Z_1Z_2Z_3Z_6\right\},SZ​={Z0​Z1​Z3​Z4​,Z0​Z2​Z3​Z5​,Z1​Z2​Z3​Z6​}, S=SX∪SZ\mathcal{S}=\mathcal{S}_X\cup\mathcal{S}_ZS=SX​∪SZ​

We would need to check if the elements of S\mathcal{S}S commute. Of course we only need to cross-check the elements in SX\mathcal{S}_XSX​ and SZ\mathcal{S}_ZSZ​. We can employ a useful graphical representation:

Each node represents a qubit while each colored section (often called plaquette) represents a stabilizer. Explicitly for XXX:

The same can be done for ZZZ. Note that different stabilizers “intersect” on an even number of qubits, therefore all the elements of S\mathcal{S}S commute.
The Steane code is an example of Color codes.

Logical qubits

Using the logical qubits result for stabilizer codes, we find that for the Steane code we have:

# logical qubits=7−6=1\# \textrm{ logical qubits} = 7-6=1# logical qubits=7−6=1

Distance

We define the following operators, called XLX_LXL​ and ZLZ_LZL​:

These operators are logical errors for the stabilizer code.
Indeed, it is easy to check that they commute with all the stabilizers, as they share either zero or two qubits with every plaquette. Moreover, by trying all the combinations of stabilizers, you can show that they don’t belong the stabilizer group, and are therefore non-trivial. By using a similar brute-force search, you can also show that they are the smallest non-trivial logical operators, thereby proving that the distance of the Steane code is d=3d=3d=3. This achieves the proof that the Steane code is a [[7,1,3]][[7,1,3]][[7,1,3]] code.
It can also be shown that these operators act as logical X,ZX,ZX,Z operators by choosing the states ∣0⟩L,∣1⟩L\ket{0}_L,\ket{1}_L∣0⟩L​,∣1⟩L​ to be the eigenstates of XLX_LXL​ and the states ∣+⟩L,∣−⟩L\ket{+}_L,\ket{-}_L∣+⟩L​,∣−⟩L​ to be the eigenstates of ZLZ_LZL​; given that the two errors anticommute this choice is valid and also fixes YL=XLZLY_L = X_LZ_LYL​=XL​ZL​. Using this convention, it is possible to prove that HL=H⊗7H_L = H^{\otimes 7}HL​=H⊗7 acts as the logical Hadamard.

Logical cosets

As an example of the Logical cosets we can consider various representative of the logical XLX_LXL​ defined above

To go from the first one to the second one, we apply a green XXX plaquette (stabilizer). To go from the second one to the last one, we apply a red XXX plaquette. Since the Steane code has only one qubit, all the XXX logicals are equivalent and there is only one coset of XXX logicals.
Given that cosets partition the set (see Equivalence class), we have that:

N(S)=[I]∪[X]∪[Y]∪[Z]N(\mathcal{S}) =[I] \cup [X] \cup [Y] \cup [Z]N(S)=[I]∪[X]∪[Y]∪[Z]

If we had multiple logical qubits, we would have three different cosets [Xi],[Yi],[Zi][X_i],[Y_i],[Z_i][Xi​],[Yi​],[Zi​] for each logical qubit.

Decoding

As an example of Decoding in stabilizer codes, let’s see how to decode a syndrome consisting of a single blue XXX-plaquette. Here are the two cosets of ZZZ operators that fit this syndrome:

The first coset is constructed by taking the only single-qubit error that fits the syndrome, shown in the top-left triangle, and applying the seven ZZZ stabilizers to it (blue, red, green, blue-red, blue-green, red-green, red-blue-green). The second coset is obtained in a similar way, starting with the two-qubit operator shown in the top-left triangle.
Assuming an i.i.d noise, we can immediately solve the “first” decoding problem: the most likely error is the one of minimum weight, that is, the first error of coset 1. We can therefore choose any correction operator in this coset as our decoding solution.
Solving the second decoding problem requires a bit more work. Let ppp be the probability that an error occurs on a given qubit, that is, the error rate of the noise channel. Each weight-kkk error has a probability

πk=pk(1−p)7−k\pi_k = p^k (1-p)^{7-k}πk​=pk(1−p)7−k

Summing the probabilities of all the elements, we get

P(coset 1)=π1+4π3+3π5P(coset 2)=3π2+4π4+π6 \begin{aligned} P(\text{coset 1}) &= \pi_1 + 4 \pi_3 + 3 \pi_5 \\ P(\text{coset 2}) &= 3 \pi_2 + 4 \pi_4 + \pi_6 \end{aligned}P(coset 1)P(coset 2)​=π1​+4π3​+3π5​=3π2​+4π4​+π6​​

Plotting those two probabilities as a function of the error rate, we can see that the first coset always has a higher probability than the second one:

This can also be shown analytically by noticing that

P(coset 1)−P(coset 2)=p(1−p)(1−2p)3(2p2−2p+1)\begin{aligned} P(\text{coset 1}) - P(\text{coset 2}) = p (1-p) (1-2p)^3 (2p^2 - 2p + 1) \end{aligned}P(coset 1)−P(coset 2)=p(1−p)(1−2p)3(2p2−2p+1)​

from which we can deduce that

P(coset 1)>P(coset 2)P(\text{coset 1}) > P(\text{coset 2})P(coset 1)>P(coset 2)

for

0<p<12 0 < p < \frac{1}{2} 0<p<21​

Therefore, both decoding formulations give the first coset as our decoding solution.

Transversal gates


Let’s see how we can implement transversal gates on the Steane code.

HHH gate

The Hadamard is easy, we can take:

HL=⨂i=17HiH_L = \bigotimes_{i=1}^{7} H_iHL​=i=1⨂7​Hi​

Since the Hadamard turns XXX into ZZZ and viceversa (see here), every X(Z)X(Z)X(Z) plaquette stabilizer will be turned into a Z(X)Z(X)Z(X) stabilizer → this is a logical gate. Same goes for XL,ZLX_L,Z_LXL​,ZL​, so our gate is actually the logical Hadamard.

SSS gate

The SSS gate is a bit more convoluted, recall that

X↦SY,Z↦SZX\overset{S}{\mapsto}Y,\quad Z\overset{S}{\mapsto}ZX↦S​Y,Z↦S​Z X↦S†−Y,Z↦S†ZX\overset{S^\dagger}{\mapsto}-Y,\quad Z\overset{S^\dagger}{\mapsto}ZX↦S†​−Y,Z↦S†​Z

Applying ⨂i=17Si\bigotimes_{i=1}^{7} S_i⨂i=17​Si​ turns XXX plaquettes into YYY ones, which are still stabilizers as

X⊗4Z⊗4=(−i)4Y⊗4=Y⊗4X ^{\otimes 4}Z ^{\otimes 4} = (-i)^4 Y ^{\otimes 4} = Y ^{\otimes 4}X⊗4Z⊗4=(−i)4Y⊗4=Y⊗4

therefore we have a logical gate, however the logical action implemented is that of S†S^\daggerS†, since

SX⊗3S†=SXLS†=SY⊗3S†SX ^{\otimes 3}S^\dagger=S {X}_L {S}^\dagger =SY ^{\otimes 3}S^\daggerSX⊗3S†=SXL​S†=SY⊗3S†

and

XLZL≐−iYL=(−i)3Y⊗3=iY⊗3X_L Z_L \doteq -iY_L = (-i)^3 Y ^{\otimes 3}= i Y ^{\otimes 3}XL​ZL​≐−iYL​=(−i)3Y⊗3=iY⊗3

so:

YL=−Y⊗3Y_L =-Y ^{\otimes 3}YL​=−Y⊗3

which corresponds to the action of SL†S_L^\daggerSL†​ as X↦S†−YX\overset{S^\dagger}{\mapsto}-YX↦S†​−Y
Therefore, to implement SLS_LSL​ we could apply S†S^\daggerS† everywhere. Another more elegant solution consists in solving the coloring problem:

Since we have an odd number of qubits, one color will correspond to more vertices than the other. In the drawing above, there are more black vertices than white vertices. However, every plaquette contains the same number of white and black qubits. Then, to implement SLS_LSL​, we apply SSS to the black qubits and S†S^\daggerS† to the white ones.
The advantage of this later implementation based on a bipartition of qubits is that it generalizes well to color codes.
